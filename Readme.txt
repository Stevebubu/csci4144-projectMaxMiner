How to run on Timberlea:

ssh Your_Username@timberlea.cs.dal.ca

2) Unzip the project folder
unzip CSCI4144-6405-ProjectCode-Group-32.zip

3) Navigate to project directory:
cd CSCI4144-6405-ProjectCode-Group-32

4) Run the Max-Miner program using java
javac MaxMiner.java

nano MaxMiner_Rules.txt

python3 Apriori.py

7) Open the generated text file from Apriori.py on Timberlea
nano RulesApriori.txt
